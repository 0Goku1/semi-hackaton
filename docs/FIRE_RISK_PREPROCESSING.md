# 기상 × 임상 × 토양 결합 전처리 설계

> 화성시 산불 위험도 · 본선 3주
> 격자 해상도 **500m 확정** (국가지점번호 체계, EPSG:5179) — 위험도 격자와 순찰 격자를 동일 ID로 통일
> 근거 수치는 모두 `data/` 실측값 (임상도 17,007폴리곤·161.5㎢, 입지토양도 15,222폴리곤·190.1㎢)
> 검증 스크립트: `analysis/12_grid500_features.py`

**핵심 요약:** 기상은 시간축에만, 임상·토양은 공간축에만 존재한다. 두 축을 **500m 격자 × 1시간**으로 강제 정렬한 뒤, **정적 취약도 × 동적 기상위험** 2단 구조로 모델링하는 것이 3주 안에 완주 가능한 유일한 경로다.

## 핵심 수치

| 항목 | 값 |
|------|-----|
| 500m 격자 학습 대상 셀 | **1,553개** (양 레이어 유효 + 산림 점유율 10% 이상) |
| 위 셀이 담는 산림 면적 | **148.9 ㎢ / 전체 161.5 ㎢ (92.2%)** |
| 산림 중심 → 수원 ASOS 거리 | **12.4 km** |
| 침엽수 면적 비율 | **31.2%** |
| 학습 행렬 (1년 · 시간 단위) | **1,553 × 8,760 = 1,360만 행** |

## 왜 500m인가 (그리고 그 대가)

500m는 폴리곤 크기에 맞춘 선택이 **아니다.** 임상도 폴리곤 중앙값이 4,375㎡(등가 한 변 66m)이므로 해상도만 보면 100m가 자연스럽다. 500m를 택한 이유는 시스템 일관성이다.

- 국가지점번호 기준점 (700000, 1300000)이 500의 배수라 500m 격자 경계가 정확히 맞는다
- **위험도 격자와 순찰 격자가 같은 ID를 쓴다** — "위험 격자를 순찰 대상으로 그대로 넘긴다"는 파이프라인이 성립한다
- 등산로에 실제 설치된 국가지점번호 표지판과 같은 체계라 현장에서 통용된다
- 실시간 추론 대상이 1,553행이라 계산이 가볍다

대가는 셀 내부 이질성이 커진다는 것이다. 같은 방식으로 100m와 비교하면:

| 지표 | 100m 격자 | 500m 격자 | 해석 |
|------|-----------|-----------|------|
| 경사도 격자평균의 표준편차 | 6.859° | 5.074° | 셀 간 변별력 26% 감소 |
| 2종 이상 섞인 셀 | 86.8% | **90.0%** | 거의 모든 셀이 혼합 |
| 최빈 수종의 면적 점유율 (중앙) | 70.4% | **50.6%** | 대표 수종이 셀의 절반밖에 못 채움 |

**결론: 500m에서는 범주형 최빈값이 셀을 대표하지 못한다.** 그래서 수종은 이름이 아니라 `conifer_ratio` 같은 **면적 비율**로 넣어야 한다. 이 결정은 500m를 택한 순간 선택이 아니라 필수가 된다.

## 기상 샘플에서 확인된 함정 4가지

1. **`-99.0` 센티널** — 습도 10%, 기압 2건, 일강수 1건. 그대로 읽으면 습도 -99%가 학습 데이터가 된다.
2. **`WD` 원형변수** — 359°와 1°를 평균하면 180°(정반대)가 나온다. sin/cos 분해 필수.
3. **`RN_DAY` 일 누적값** — 시간 강수로 쓰면 강도가 수십 배 부풀려진다.
4. **강수 결측을 0으로 채우면** — "비 안 온 건조한 시각"으로 뒤집혀 라벨과 정반대로 학습된다.

## 문제의 본질: 세 축의 해상도가 전부 다르다

| 축 | 임상도 · 입지토양도 | 기상 (ASOS) | 정렬 방법 |
|----|---------------------|-------------|-----------|
| 공간 | 불규칙 폴리곤, 등가 한 변 60~66m | 점(관측소). 화성 내부 0개 | 500m 격자로 리샘플 (비율 피처 필수) |
| 시간 | 정적 (연 단위 갱신) | 1시간 간격 연속 | 정적 피처를 시간축에 브로드캐스트 |
| 값 유형 | 범주 + 연속 혼재 | 연속 + 원형(풍향) | sin/cos 분해, 면적가중 평균·비율 |
| 결측 | NaN (임상 19.3%, 토양 39.6%) | `-99.0` 센티널 | 센티널 → NaN → 범주화 |

## 화성시 산림 프로파일 (500m 셀 기준)

### 임상 유형별 면적 비율 (FRTP_CD)

| 유형 | 비율 |
|------|------|
| 활엽수 | 48.9% |
| 침엽수 | 31.2% |
| 혼효림 | 13.4% |
| 무립목·기타 | 6.6% |

`conifer_ratio`(셀 내 침엽수 면적 비율): 평균 0.319, 중앙 0.272, 침엽수가 전혀 없는 셀 16.7%, 0.5 이상인 셀 24.5%

### 사면 방위 (EIGHT_AGL) — 남향 계열 최다

`EIGHT_AGL`은 8방위 코드가 아니라 **연속 각도(0~360°)** 다. 고유값이 3,500개이고 `-1`이 평탄지·결측(1.7%)이다. 코드가 아니므로 최빈값이 아니라 **sin/cos 면적가중 평균**으로 집계해야 한다.

| 방위 | 비율 | | 방위 | 비율 |
|------|------|---|------|------|
| N | 8.2% | | S | **17.5%** |
| NE | 9.2% | | SW | 16.0% |
| E | 11.2% | | W | 13.4% |
| SE | 14.6% | | NW | 10.0% |

남향계(SE+S+SW) 합계 **48.2%**. 방위 집중도(합성벡터 크기 R) 중앙값 0.59로, 셀 내 방위가 어느 정도 일관된다.

화성은 셀 면적가중 고도 중앙값이 **41.1m**(사분위 26.2~66.1, 최대 252.9m)인 저산지라 **사면방위가 핵심 변별 축**이고 고도 단독 변별력은 낮다.

### 지형 · 연료량

| 항목 | 중앙값 | 사분위 | 비고 |
|------|--------|--------|------|
| 경사도 (LOCTN_GRDN) | 12.5° | 9.0~15.9° | 최대 33.0°, 결측 0% |
| 고도 (LOCTN_ALTT) | 41.1 m | 26.2~66.1 m | 결측 0% |
| 영급 (AGCLS_CD) | 4.0 | 3.8~4.1 | 4영급 편중, 결측 19.3% |
| 수고 (HEIGHT) | 11.0 m | 6.2~13.5 m | 결측 19.7% |

### 수종 혼합도 — 이름 하나로 대표할 수 없다

| 항목 | 값 |
|------|-----|
| 셀 내 수종 수 | 중앙 5종, 평균 5.1종, 최대 13종 |
| 2종 이상 섞인 셀 | 90.0% (단일 수종 셀 10.0%) |
| 최빈 수종 면적 점유율 | 중앙 50.6%, 하위 25% 37.6% |

## 전처리 파이프라인 8단계

### 0. 좌표계 · 경계 정렬 (0.5일)
- 모든 레이어 `EPSG:5179` 고정
- `EPSG:4326` 변환은 지도 렌더링 직전만
- **화성 4구(만세·효행·병점·동탄) 경계 폴리곤 별도 확보 필요**

### 1. 분석 격자 생성 500m (0.5일)
- 국가지점번호 500m 격자 — `src/grid.py`의 `grid_polygons()` / `encode()` 사용
- 기준점 (700000, 1300000)에 스냅되므로 경계가 정확히 맞음
- **결과: 학습 대상 셀 1,553개** (양 레이어 유효 + 산림 10% 이상)

### 2. 정적 피처 격자화 (3일)
- 연속형: 면적가중 평균 / **범주형: 최빈값 대신 면적 비율** (500m에서 최빈값은 셀의 절반도 대표하지 못함)
- `conifer_ratio` = 침엽수 면적 ÷ 셀 내 산림 면적 (최강 공간 피처)
- `forest_ratio` = 산림 면적 ÷ 셀 면적 (연료 총량 대리)
- `EIGHT_AGL`: `-1` → NaN 후 sin/cos 면적가중 분해 (원형변수 평균 금지)
- 결측 삭제 금지 → `무립목`/`미조사` 별도 범주

### 3. 기상 원본 정제 (2일)
- 파서: `comment='#'`, 12자리 `YYYYMMDDHHMI` → KST tz-aware
- `-99/-99.0/-9/-999` → NaN
- 물리 범위: TA -40~50℃, HM 0~100%, WS 0~60, WD 0~360
- 1~3h 공백 선형보간, 그 이상 인접 관측소 회귀

### 4. 기상 파생변수 (3일)
- 풍향: `u = -WS·sin(WD)`, `v = -WS·cos(WD)`
- `RN_DAY` 시간 차분 + 자정 리셋
- VPD, 실효습도, FWI 계열, `hour_sin/cos`, `doy_sin/cos`

### 5. 시공간 조인 (2일)
- 화성 ASOS 없음 → 수원(119) 12.4km, 반경 40km IDW 보간
- 기온 고도보정: `T − 0.0065 × (셀고도 − 관측소고도)` (최대 ~1.9℃)
- **대안: 기상청 동네예보 5km 격자 (3주 일정에 더 안전)**

### 6. 라벨링 & 샘플링 (3일)
- Positive: (격자, 산불 발생시각) / Negative: 의사부재 표본 1:10~1:50
- **화성 단독 학습 불가 → 경기도/전국 전이 학습**
- 공간 블록 CV + 최근 1년 시간 격리 (무작위 CV 금지)

### 7. 학습 · 등급화 · 서빙 (4일)
- **분위수 5등급** (절대 임계값 금지)
- Isotonic 보정 + SHAP 설명
- PostGIS 적재 → GeoJSON/벡터타일 서빙

## 기상 파생변수

| 파생변수 | 계산 | 산불 연결 |
|----------|------|-----------|
| VPD | `es(T)·(1−RH/100)` | 연료 건조 속도 |
| 실효습도 | `He = (1−r)·Σ rⁿ·Hₙ` (r=0.7, 5일) | 산림청 공식 기준 |
| 무강수 지속시간 | 마지막 1mm+ 강수 이후 경과 | 미세연료 건조 |
| 누적강수 24/72/168h | rolling sum | 연료층별 습윤 |
| FFMC/DMC/DC | Van Wagner 재귀 | 표층~심층 수분 |
| ISI/BUI/FWI | 위 3개 + 풍속 | 국제 표준 화재강도 |
| u/v 풍성분 | `-WS·sin/cos(WD)` | 사면+바람 내적 |

## 모델 구조

```
정적 취약도 S(x)  [연 1회]  ← 임상·토양·지형 (1,553셀)
        ×
동적 기상위험 W(t,x)  [1시간]  ← FWI·실효습도·VPD
        ↓
LightGBM → 확률 → 분위수 5등급 → 지도 → 순찰 배정(동일 격자 ID)
```

| 후보 | 판단 |
|------|------|
| **LightGBM** | 주력. SHAP으로 심사 설명 가능 |
| 로지스틱 회귀 | 기준선 대조군 |
| R = Sᵅ × Wᵝ | 산불 이력 부족 시 대비책 |
| CNN/ConvLSTM | 보류 (과적합 위험) |

## 리스크 3가지

1. **화성 4구 경계 없음** — 구별 등급 표출 불가. 최우선 확보.
2. **산불 이력 표본 수 미확인** — 화성 단독이면 지도학습 불가. 팀원에게 건수·범위 확인 필수.
3. **500m 셀 내부 이질성** — 최빈 수종이 셀 면적의 절반밖에 못 채운다. 모든 범주형을 비율 피처로 전환하는 것이 전제이고, 이를 지키지 않으면 500m 선택이 그대로 성능 손실로 이어진다.
