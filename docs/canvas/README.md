# Cursor Canvas (이관용)

새 PC에서 Cursor로 이 repo를 연 뒤, 아래 4개 파일을 Cursor Canvas 폴더로 복사하세요.

**Windows:** `%USERPROFILE%\.cursor\projects\<워크스페이스-폴더명>\canvases\`  
**macOS/Linux:** `~/.cursor/projects/<워크스페이스-폴더명>/canvases/`

복사 대상:
- `3week-plan.canvas.tsx`, `3week-plan.canvas.data.json`
- `grid-system.canvas.tsx`, `grid-system.canvas.data.json`

Cursor에서 프로젝트를 한 번 연 다음 `canvases` 폴더가 생기면 그 안에 넣으면 됩니다.
